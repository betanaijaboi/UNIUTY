# Privacy Notice — UNIUTY University Portal (Demo)

Last updated: 2026-08-25

UNIUTY is a demo application, not a production university system. This
notice explains what happens to data in the live demo.

## What we collect

If you use the published demo credentials, anything entered — student
records, results, course data, audit entries — is stored in a shared
MongoDB database and is visible to anyone using the same published
credentials for that role.

**Do not enter real personal, academic, or biometric data.** Use
fictional data only.

## Biometric data

The demo's biometric login is simulated (see `js/biometric.js`) — no real
biometric data is captured or stored by this demo in its current form.

## Where data is stored

- **Database:** MongoDB
- **Authentication:** JWT-based session tokens

## Data retention

Demo data may be reset or wiped at any time without notice.

## Your rights

Since this demo is not designed to process real personal data, there's no
real-user deletion process to run — don't put in data you'd need deleted.
If real personal data was accidentally entered, contact us and we'll
remove it.

## Nigeria Data Protection Act (NDPA) note

Biometric data is classified as sensitive personal data under NDPA 2023.
If this project is ever turned into a real production university system
processing real biometric or academic data, this notice must be replaced
with a full NDPA-compliant privacy policy covering lawful basis for
processing, sensitive-data safeguards (encryption, DPIA, minimal
retention), and data-subject rights.
