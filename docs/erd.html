Database Design & Entity-Relationship Diagram

PostgreSQL schema design for the UNIUTY Portal, covering 14 core tables with all primary keys, foreign keys, indexes, and relationship cardinalities.

Database Engine: PostgreSQL 16  |  ORM: Prisma / Knex.js  |  Naming Convention: snake_case  |  All timestamps: TIMESTAMPTZ (UTC)

1. Overview

The database is organized around a central users table from which role-specific profiles (students, staff) extend via one-to-one foreign key relationships. Academic entities (courses, departments) are linked to transactional tables (results, attendance, fees, payments) through normalized join structures. Security and compliance are handled by append-only biometric_log and audit_log tables.
