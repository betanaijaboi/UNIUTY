Branch Conditions: If credentials are invalid, the system increments a failed_attempts counter. At 5 failures, the account is locked for 30 minutes and an unlock email is dispatched. Biometric challenge is only presented to Admin and VC roles, or when the session is initiated from a registered biometric terminal. Students and Lecturers accessing from unregistered devices skip the biometric challenge and proceed with JWT only.

Branch Conditions: A quality score below 70% (e.g. smudged fingerprint, poor lighting for facial scan) triggers up to 3 automatic retries before escalating. If 3 consecutive verifications fail for the same user within 5 minutes, an automated alert is sent to the duty administrator. The student is held and directed for manual identity verification using their student ID card.

Branch Conditions: Payment reconciliation is webhook-driven — the portal does not poll the gateway. Branch Conditions: Applicants who do not meet the UTME cutoff are automatically marked as Rejected; they receive a polite rejection email. Acceptance deadline is 14 days from offer date; offers not accepted within the window are automatically withdrawn.
