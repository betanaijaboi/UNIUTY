System Architecture

A layered architecture diagram and full technology stack for the UNIUTY Portal, showing how clients, application services, data stores, biometric hardware, and third-party integrations interact.

Pattern: Layered MVC + Service-Oriented  |  Protocol: HTTPS / REST  |  Auth: JWT (HS256)  |  Deployment: Containerised (Docker + Kubernetes)

1. Architecture Overview

The UNIUTY Portal is structured as a six-layer system. Clients interact with the application through a secure HTTPS boundary. The application layer hosts all business logic, with a dedicated BiometricAPI plugin interface decoupling hardware from core logic. Persistence is handled by PostgreSQL as the primary datastore, with Redis for sessions and caching. All external dependencies (payment gateways, email, SMS) are isolated behind service adapters to allow future substitution.

2. Client Layer

Biometric Hardware Terminal

All clients communicate over TLS 1.3 (HTTPS). Biometric terminals connect to the application layer via the BiometricAPI USB/IP bridge. No native app is required — the portal is a responsive web application delivered as a Progressive Web App (PWA).
↕ HTTPS / TLS 1.3

All REST endpoints are protected by JWT middleware. Role-based access control (RBAC) is enforced at the route level. The BiometricAPI interface communicates with hardware drivers via a defined plugin contract — swapping hardware vendors requires only a driver update, not an API change.

5. Biometric Hardware Layer

Biometric Hardware Layer — Physical Devices
Fingerprint Scanner
500 dpi optical / capacitive sensor
Retina Scanner
Near-infrared iris capture
Facial Recognition Camera
3D depth sensing, liveness detection
NFC Reader
ISO 14443 / 15693 compliant
Hardware communicates with the BiometricAPI Plugin Interface via USB or TCP/IP (for networked terminals). The BiometricAPI abstracts all hardware-specific SDKs behind a common interface. Biometric templates are encrypted (AES-256) before transit to the application layer and are never stored in plaintext.
↕ HTTPS API / SMTP / Webhook
