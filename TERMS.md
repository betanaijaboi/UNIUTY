# Terms of Use — UNIUTY University Portal (Demo)

Last updated: 2026-08-25

**This is a portfolio/demonstration project, not a real university system.**
UNIUTY is a technical demo of a role-based university management portal
built to show engineering work. "University of Unity" is a fictional
institution — this is not affiliated with any real university.

## 1. Shared public demo credentials

This repository's README publishes demo login credentials for every role
(Administrator, Vice Chancellor, Lecturer, Student). Anyone with these
credentials can log in and see/modify the same shared demo data. This
means:

- **Do not enter real names, real student records, real grades, or any
  real personal data into this demo.** Use fictional data only.
- Anything entered may be visible to, or edited/deleted by, anyone else
  using the same published credentials.
- Demo data may be reset at any time without notice.

## 2. Biometric authentication is simulated

The biometric login flow (`js/biometric.js`) is a hardware-plugin
API/simulation for demonstration purposes. No real biometric data (real
fingerprints, face scans) is captured, stored, or processed by this demo
in its current form.
